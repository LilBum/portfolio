# Alexander Urs-Badet’s portfolio

A static portfolio built with React, TypeScript, and Vite.

```sh
npm run dev      # local development
npm run build    # type-check and generate dist/
npm run preview  # serve the production build locally
```

Project descriptions, experience, and contact links live in `src/data/`. The site presents public project summaries and a short professional bio. Keep private research material and source excerpts outside the app and its `public/` directory.

The existing site is hosted at [alexub-portfolio.vercel.app](https://alexub-portfolio.vercel.app).
